The diagram file `mica-doc.drawio` was generated using the online [app](https://app.diagrams.net/). 

To load the diagram simply navigate to the page above and select `Open Existing Diagram`.

The branded diagrams in `../images` are drawn from the SVG sources in this folder (OBiBa design system
colors, Sora and Instrument Sans fonts from `../_static/fonts`). After editing an SVG, regenerate the PNGs
(2x resolution, requires Chromium):

```
./render.sh                 # all diagrams
./render.sh mica-dar-*.svg  # some diagrams
```
